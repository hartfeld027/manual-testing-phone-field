# Тестирование поля «Телефон» - MY-LK Регистрация

Проект демонстрирует полный цикл **ручного тестирования** одного поля формы регистрации - **«Телефон»** - в соответствии с требованиями компании **O!**.  
Все артефакты (требования, тест-дизайн, тест-кейсы, баг-репорты) созданы лично мной в рамках стажировки.

---

## Требования к полю «Телефон»

Согласно техническому заданию:

- Разрешены **только цифры**.
- Номер должен содержать **ровно 12 символов**.
- Допустимые префиксы оператора **O!**:
  - `99670` — диапазон `996700`–`996709`
  - `99650` — диапазон `996500`–`996509`
- **Запрещены**:
  - Номера других операторов (Beeline `77`, `22`; MegaCom `55`, `75`, `99`, `510–519`, и др.)
  - Длина ≠ 12 символов
  - Буквы, пробелы, спецсимволы (`-`, `(`, `)`, `+`, и т.п.)
  - Иностранные номера (не начинающиеся с `996`)

> **Ожидаемое поведение**:  
> При вводе недопустимого номера поле подсвечивается красным, отображается сообщение:  
> *«Номер должен принадлежать оператору О!»* или *«Номер должен содержать ровно 12 цифр»
